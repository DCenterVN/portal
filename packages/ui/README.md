# @dcentervn/ui

Accessible UI primitives, layout shells, and decoupled presentational views for the Việt Sạch platform.

## Features

- **Primitives**: `Alert`, `Badge`, `Button`, `Card`, `Input`, `Skeleton`.
- **Shells**: `AppShell` (responsive admin navigation), `AuthShell` (with logo slot), `PublicShell`, `StorefrontShell`.
- **Auth Views**: Pure presentational views (`LoginView`, `RegisterView`, `ActivateView`, `ForgotPasswordView`, `ResetPasswordView`, `EmailChangeView`, `EmailConfirmView`) receiving data and actions via props.

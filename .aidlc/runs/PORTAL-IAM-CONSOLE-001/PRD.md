# PRD — PORTAL-IAM-CONSOLE-001

Build an operator console for Resort IAM V1.

## Goals

- Let platform operators inspect users, resorts, memberships, roles and location data.
- Provide a guarded API Lab for public and internal service contracts.
- Audit operator actions without storing sensitive payloads.
- Support Vietnamese UI with English catalog foundation.

## Non-goals

- Customer-facing resort portal.
- Owner impersonation.
- Direct browser access to internal auth/org APIs.

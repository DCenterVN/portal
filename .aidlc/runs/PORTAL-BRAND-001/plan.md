## Scope

- Why it drifted: the decision lives in `platform-docs/ui/2026-09-24-brand-dna-v3-tu-agromind-tutitor.md` §2–4, but it never reached the pipeline.
  - `platform-docs/ui/tokens.json` still holds the old teal/terracotta palette.

## UX

- AuthShell brand panel: `bg-primary` `#1B5E20` with white text (7.87:1). The form side is `bg` `#F6F8F3` with `ink` `#14291A` (14.42:1).
- Submit buttons:
  - login/forgot/reset use primary (green).
  - register "Tạo tài khoản" uses accent (tomato), as in the kit.
- Password field, as in the kit:
  - The eye button sits inside the input on the right, is 40×40 px, and is the next Tab stop.
  - It starts hidden. Pressing it shows the text, switches the icon to EyeOff and the label to "Ẩn mật khẩu".
  - Each field has its own state.
  - It is disabled while submitting.
- States are unchanged: idle, submitting, error (`role="alert"`), done.
- The browser's "save password?" prompt stays for real users. `autocomplete` is `current-password`/`new-password`.

## Technical definition
- FE layering (platform-docs/standards/frontend.md): ui → patterns → layout → features → app. `PasswordInput` goes in `components/patterns/`.
- Tailwind v4: `@theme inline` in globals.css exposes `--color-*` as utilities (`bg-primary`, `text-ink`, `font-display`).

## Design
- `app/tokens.generated.css`: regenerated by `python3 platform-docs/scripts/uigen.py tokens --root . --write` (run from `ticket/`). Never hand-edited.
- `app/globals.css`:
  - `@import "./tokens.generated.css";`
  - In `:root`, the shadcn vars map as follows:
    - `--background: var(--color-bg)`
    - `--foreground/--card-foreground/--popover-foreground: var(--color-ink)`
    - `--card/--popover: var(--color-surface)`
    - `--primary: var(--color-primary)`, `--primary-foreground: var(--color-primary-ink)`
    - `--secondary/--muted/--accent-soft: var(--color-tint)`
    - `--muted-foreground: var(--color-muted)`
    - `--accent: var(--color-accent)`, `--accent-foreground: var(--color-accent-ink)`
    - `--destructive: var(--color-danger)`
    - `--border: var(--color-line)`, `--input: var(--color-input-border)`
    - `--ring: var(--color-focus)`
  - Dark comes free, because the generated file carries the dark values.
- `components/ui/button.tsx`: variants follow the kit's `.btn-primary/.btn-accent/.btn-quiet/.btn-ghost`, with min-height 44, radius md, `active:scale-[.98]`.
- `components/patterns/password-input.tsx`: `Input` plus a ghost icon button, lifted from `features/auth/login-form.tsx:50-53`.

## Found during the UI run (2026-09-26, RUN=1790391483)
- Every page logs `404 /favicon.ico`: the portal has no icon. The grader's G7 console gate fails on it, and the brand kit has a leaf mark. Fix: `app/icon.svg` (Next.js app-router convention injects `<link rel="icon">`), with a leaf in `#1B5E20`.
- `proxy.ts` only lets `/favicon.ico` through. Without a session, `/icon.svg` returns 307 to `/login?redirect=%2Ficon.svg`, so logged-out visitors (every auth page) get a broken icon. Fix: add `/icon.svg` to `PUBLIC_PREFIXES`, with a test that it returns 200 without a cookie.
- `/robots.txt` and `/sitemap.xml` (`app/robots.ts`, `app/sitemap.ts`) are also sent to `/login` without a session. Same class of bug, but it affects SEO and not this task → PORTAL-PUBLIC-ASSETS-001.
- Grader false positives fixed in `PORTAL-AUTH-UI-001/anti_check.py`:
  - G5 now allows identical images only when the expected state is the same. 08/09/14 are all the home page. A mutation test that copies the 01 image onto 02 still FAILs.
  - G7 now ignores the Playwright MCP dump header `Total messages: …`.

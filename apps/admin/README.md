# @dcentervn/admin

Operations and platform management application for Việt Sạch.

Runs on port `3001`.

## Features

- **Operations Dashboard**: `/ops/dashboard`
- **Component Gallery (Living Styleguide)**: `/dev/components` (dev mode only)
- **System Administration**: `/system`
- **Reverse Proxy**: Proxies `/auth/*` and `/.well-known/*` to auth microservice (`:8080`).
